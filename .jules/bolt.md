## 2024-05-27 - O(N²) array lookup to O(N) Set lookup in local datastore
**Learning:** The application uses a local JSON file (`data/store.json`) as a database fallback. When performing batch operations like `addJobs`, relying on `.some()` nested inside a `for` loop to enforce uniqueness creates an O(N²) bottleneck, causing severe delays on the main thread when processing batches against thousands of existing entries.
**Action:** When working with the local JSON store for relational data or uniqueness checks, extract existing values into `Set` or `Map` data structures first. This enables O(1) lookups, changing the overall complexity from O(M * N) to O(M + N). Always ensure these sets/maps are dynamically updated during the loop to catch duplicates within the batch itself.
