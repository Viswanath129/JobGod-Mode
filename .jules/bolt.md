## 2024-05-24 - Relational mapping and duplicate checking O(n^2) bottleneck
**Learning:** Found O(n^2) complexity bottlenecks in local JSON store operations when doing duplicate checks inside a loop in `addJobs` (using `.some()` internally) and doing relational mapping inside `.map` in `getJobs` and `getApplications` (using `.find()`). As the local array size scales, these synchronous main-thread operations degrade performance heavily.
**Action:** Replaced internal array `.some()` inside loop with an O(1) `Set` updated on every item processing to avoid duplicates inside the batch, and replaced `Array.find()` lookups during mapping with pre-populated O(1) `Map` instances mapping IDs to models. Always use `Set`/`Map` data structures instead of arrays for nested iterative lookups.
