## 2025-07-05 - Local JSON Store Uniqueness Checks
**Learning:** The application architecture uses a local JSON file as a fallback database. When checking for duplicate entries during a batch `addJobs` operation, using `Array.prototype.some` creates an O(N*M) performance bottleneck on the main thread, growing worse as the store expands. Empty identity fingerprints (`"|||"`) can cause false positive duplicates if not explicitly ignored.
**Action:** When implementing uniqueness checks or relational operations on the local fallback store, always utilize `Set` or `Map` data structures for O(1) lookups. Ensure these structures are dynamically updated within the loop so that duplicates are effectively prevented within the same batch. Always gracefully handle empty core identity markers to prevent false positive matches.
