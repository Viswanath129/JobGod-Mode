## 2024-06-09 - Local JSON store N+1 operations blocking main thread
**Learning:** The fallback local JSON store (`data/store.json`) can become a major CPU bottleneck during batch job insertions. The `addJobs` method was using `Array.some()` inside a `for...of` loop to check uniqueness against existing jobs (`sameJobIdentity`). Since this compares multiple string fields (URL, externalId, and a composite fingerprint) and normalizes them inside the O(N^2) loop, it blocks the main thread heavily when storing hundreds of scraped jobs.
**Action:** When implementing local-file based storage fallbacks, always use O(1) structures like `Set` or `Map` to check for duplicates before iterating over batch inputs, and make sure to dynamically update these sets within the batch loop so intra-batch duplicates are also caught without O(N) operations.
