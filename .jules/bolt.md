## 2024-05-22 - JSON Store O(n^2) Duplicate Check Bottleneck
**Learning:** The local JSON store implementation (`src/lib/store.ts`) had an O(n^2) bottleneck in `addJobs`. When adding a batch of `M` new jobs, it called `store.jobs.some(sameJobIdentity)` for each job, scanning the entire list of `N` existing jobs. Since `sameJobIdentity` involves multiple string normalizations and concatenations, this created severe blocking on the main thread for large datasets.
**Action:** When working with local data structures (like arrays storing database records), always use `Set` or `Map` to pre-calculate identities for O(1) lookups during batch operations. Critically, these O(1) lookup structures must be dynamically updated during the loop to catch duplicates *within* the incoming batch itself.
