## 2023-10-27 - O(n^2) Bottleneck in Local JSON Batch Operations
**Learning:** Checking for duplicates using nested loops (`some` within a loop) on the main thread for the local JSON store (`data/store.json`) creates an O(n²) bottleneck during batched data syncs (like `addJobs`). Using `Set` structures created outside the loop turns this into O(n), but when working with batched data, the `Set`s must be updated dynamically *inside* the loop. Otherwise, duplicates present within the incoming batch itself won't be caught.
**Action:** Always prefer O(1) lookups (like `Set` or `Map`) for relational integrity checks on the main thread. Ensure these structures are dynamically updated within the loop processing logic to handle internal duplicates in batch payload arrays correctly.
